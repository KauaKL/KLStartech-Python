# 🌌 DashFin Estelar — by KLStarTech

Dashboard financeiro inteligente com IA de voz e automação em tempo real.  
Desenvolvido por **Kauã Lima (KLStarTech)**.

---

## 🚀 Tecnologias Usadas

- Python 3.12+
- Streamlit
- Prophet (IA de previsão)
- Pyttsx3 (voz da Estelar)
- SMTP (envio de e-mails automáticos)
- Plotly, Matplotlib, Pandas

---

## ⚙️ Instalação

```bash
pip install -r requirements.txt
```
